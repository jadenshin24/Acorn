# Acorn Search

Acorn Search는 간단하고 빠른 웹 검색을 제공하는 정적 홈페이지입니다.

## 프로젝트 이름
Acorn Search

## 설명
간단하고 빠른 웹 검색 홈페이지

## 사용 방법
1. 브라우저에서 `index.html`을 열거나 정적 웹 호스팅에 업로드합니다.
2. 검색창에 검색어를 입력합니다.
3. Enter 키 또는 "Acorn 검색" 버튼을 눌러 검색합니다.
4. 일반 검색어는 Google 검색 페이지로 이동합니다.
5. `youtube.com`, `naver.com`, `https://github.com` 같은 URL은 직접 이동합니다.
6. `http://` 또는 `https://`가 없는 주소는 자동으로 `https://`를 붙여서 이동합니다.

## 동작 방식
- 검색어가 비어 있으면 이동하지 않습니다.
- Enter 키와 검색 버튼 모두 지원합니다.
- 검색어는 `encodeURIComponent()`로 안전하게 URL 인코딩됩니다.
- 페이지가 로드되면 검색창에 자동으로 포커스됩니다.
- 모바일과 데스크톱 모두 반응형으로 동작합니다.

## Vercel 정적 사이트 배포 방법
1. GitHub 저장소에 프로젝트를 업로드합니다.
2. [Vercel](https://vercel.com)에 로그인합니다.
3. "Add New Project"를 선택합니다.
4. 이 저장소를 연결합니다.
5. 기본 설정대로 프로젝트를 생성합니다.
6. 정적 사이트가 자동으로 배포됩니다.
7. 생성된 도메인으로 접속해 사용할 수 있습니다.

## 참고
- Google 로고나 상표는 사용하지 않고 독립적인 "Acorn Search" 디자인으로 구성했습니다.
- CSS와 JavaScript는 `index.html` 하나에 포함되어 있어 별도의 빌드 과정 없이 바로 실행됩니다.
